Game Information:
Stranded on an unknown island, your only hope is to send a letter to the sea. Your only hope is for the waves to guide through to the next island.

This is our first attempt for a Game Jam as a group. We decided to go with something simple and to take the theme... well, quite literally.


Controls: WASD or Arrow keys for movement.



Used fonts: Neptun CAT Font, Nothing You Could Do
Used sounds: Freesound, Pixabay
